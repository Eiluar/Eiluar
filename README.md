## Perfil Profesional

Perfil orientado al desarrollo de software con pasión por la tecnología, el aprendizaje continuo y la creación de soluciones digitales funcionales. 

Actualmente en proceso de fortalecimiento de habilidades en desarrollo, bases de datos y tecnologías web, con el objetivo de avanzar profesionalmente hacia el stack completo (Full Stack). El enfoque de trabajo se basa en la responsabilidad, la organización y una alta disposición para integrar nuevas herramientas tecnológicas.

El interés principal radica en colaborar en proyectos que permitan potenciar capacidades técnicas y adquirir experiencia sólida en el despliegue de aplicaciones y sistemas informáticos que aporten valor real.
